# 验收清单

对照 Clash Verge Rev v2.5.9 `160bb4fe` 的截图勾选。P0 是 M2 范围。亮色、暗色各走一遍 P0。窄窗（宽 < 900，接近最小 520）和默认窗（940×700）各看一次首页和设置的列数。

规格：`pages/`、`design-tokens.md`、`i18n/`。P1/P2 只核对大纲里已经写死的点，不要求像素级。

## P0 设计令牌

- [ ] 亮色主色 `#007AFF`，暗色 `#0A84FF`；背景纸色亮 `#F5F5F5`、暗 `#2E303D`
- [ ] 页面内容区亮 `#ECECEC`、暗 `#1e1f27`；卡片亮白、暗 `#282a36`
- [ ] 页面标题 20px/700，卡片标题 18px，设置分组 16px/700
- [ ] 字体含微软雅黑 UI 与系统 UI 字体；Windows 有 twemoji
- [ ] 分隔线是 6% 黑或白，不是实线灰
- [ ] 除粘性分组头和拖拽中元素外，卡片没有投影

## P0 首页

- [ ] 标题「首页」，三个页头按钮：轻量、手册、首页设置
- [ ] 默认八张可见卡，md 以上两列，流量卡整行；窄屏单列
- [ ] 首页设置九个勾选，取消不保存，保存后立即显隐
- [ ] 无订阅：订阅卡空态「导入订阅」+「点击导入订阅」，点击进 `/profile`
- [ ] 有订阅：名称、来源 host、更新时间、流量进度条、到期；更新中图标旋转
- [ ] 当前节点：信号色按 200/300/500/10000 分档；延迟 Chip 按 250/400 分档（两套阈值）
- [ ] 直连时测速按钮禁用，节点下拉禁用，出现直连 Chip
- [ ] 网络卡两个 Tab，角标只在真正开启时出现；描述条带问号
- [ ] 模式卡三按钮，选中项下方有 primary 短竖线，描述跟模式走
- [ ] 流量四格或六格（内存开关），速度带 `/s`；点击图表切换平滑/线性
- [ ] 网站测试默认 Apple/GitHub/Google/YouTube，可拖拽，失败后不一直「测试中」
- [ ] IP 默认遮住，眼睛可切换；自动刷新关时不倒计时
- [ ] Clash 信息五行；运行时间 `时:分:秒`
- [ ] 系统信息：自启 Chip 可点，Sidecar 模式有下划线

## P0 代理

- [ ] 标题「代理组」；规则/全局/直连，当前实心
- [ ] 直连整页只有收件箱图标和「直连模式」
- [ ] 无订阅、未激活、内核不可用、无节点四种空态按钮不同
- [ ] 分组头：类型、当前节点、数量 Chip、六枚工具、展开箭头
- [ ] 排序三态图标会变；过滤 600ms 防抖；`delay<200`、`type=ss` 可用
- [ ] 节点高 40，选中左边 3px 条；hover 出「检测」；测试中转圈
- [ ] 列数随窗口变（自动：≥600 两列，>1024 三列）
- [ ] 规则/全局右侧有字母导航
- [ ] 链式代理先确认；空链有「关闭」；少于 2 个节点不能连接
- [ ] 代理集合可打开并更新

## P0 订阅

- [ ] 路由是 `/profile`，标题「订阅」
- [ ] 导入框空时是粘贴，有字是清除；Enter 导入；非法 URL 报错
- [ ] 新建打开类型/名称/描述；远程才有链接和四个开关
- [ ] 更新间隔 < 1440 分钟出橙色提示，仍能保存
- [ ] 卡片网格最宽约 480；选中左边 3px 条，标题变主色
- [ ] 右键菜单远程比本地多首页（有 home 才有）、二维码、两个更新
- [ ] 删除先确认「此操作不可逆」
- [ ] 批量：全选/半选/删除禁用/计数/完成
- [ ] 拖拽排序；拖 YAML 文件可导入
- [ ] 底部分割线下两张全局扩展卡

## P0 设置

- [ ] 四块：系统、Clash、Verge 基础、Verge 高级；窄屏单列
- [ ] 页头手册 / Telegram / GitHub
- [ ] 可点行右侧是箭头；异步时变转圈并禁用
- [ ] Linux 没有「托盘点击」
- [ ] 语言下拉是语言自称，不是翻译句子
- [ ] 主题三态、托盘点击五项、复制环境类型、启动页八项
- [ ] 启动脚本只能浏览，不能手打；有值才出现清除
- [ ] Clash：允许局域网齿轮开网卡；DNS 无订阅时开关禁用
- [ ] DNS 覆写若要确认，按钮是「仍然启用 / 保持关闭」
- [ ] 端口：Windows 无 redir，仅 Linux 有 tproxy；重复端口不能保存
- [ ] 主题设置八个色块，placeholder 是当前模式默认色
- [ ] 布局：流量图、内存、悬停导航默认开；悬停延迟默认 280ms
- [ ] 杂项列数「自动」对应内部值 6
- [ ] 热键八项；备份含定时（默认关、间隔 24 小时、1–168）和 WebDAV
- [ ] 版本行可复制，文案带 `v`
